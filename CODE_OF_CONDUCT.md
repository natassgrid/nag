# Contributor Code of Conduct

## Our Pledge

We as contributors, maintainers, and community members pledge to make participation in the NAG (Next-generation Assessment Grid) community a respectful, welcoming, inclusive, and harassment-free experience for everyone, regardless of:

- Age
- Body size
- Disability
- Ethnicity
- Gender identity or expression
- Level of experience
- Nationality
- Personal appearance
- Race
- Religion
- Sexual orientation
- Technical background

Our goal is to build an open, collaborative, and professional community that advances secure and trustworthy digital assessment systems.

---

# Our Standards

Examples of behavior that contributes to a positive environment include:

- Being respectful and considerate
- Welcoming newcomers
- Accepting constructive feedback
- Focusing on technical discussions
- Helping others learn
- Writing inclusive documentation
- Reviewing pull requests professionally

Examples of unacceptable behavior include:

- Harassment or discrimination
- Personal attacks
- Trolling
- Publishing private information
- Offensive language
- Spam
- Intentionally disruptive behavior

---

# Scope

This Code of Conduct applies to:

- GitHub repositories
- Issues
- Pull Requests
- Discussions
- Documentation
- Community meetings
- Chat platforms
- Conference presentations related to NAG

---

# Enforcement

Project maintainers are responsible for enforcing this Code of Conduct.

They may:

- Request changes
- Remove inappropriate content
- Temporarily suspend contributors
- Permanently ban repeat offenders

---

# Reporting

Please report unacceptable behavior by opening a private security or community issue or contacting the project maintainers.

All reports will be handled confidentially.
